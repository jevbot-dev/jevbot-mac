# Jevbot 0.2.3

- Organize the app store by product and platform target, with separate macOS, Windows, iOS and Android metadata and editorial card ordering.
- Connect an existing Obsidian installation by installing its MCP bridge from the same Obsidian card. Guide users to enable the official CLI when needed.
- Select a vault per task, keep other tasks isolated, and verify note creation and appends by reading the content back.
- Show Obsidian vault lists, search results and note edit verification through read-only A2UI in the chat window.
- Display Obsidian and CalcGrid CLI names even when their connections or executables are temporarily unavailable.
- Distinguish Install, Connect and Open buttons. Keep card clicks inactive and use subtle hover feedback.
- Present Developer as an application card, with its bridge managed as a connection component.

This pre-1.0 update replaces catalog v1 and previous installation receipts without migration. Existing application files and user data are preserved. Reconnect applications from the store and pair phone applications again when required.
