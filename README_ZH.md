## 开始使用

**Apple Silicon Mac · macOS 14+**

1. 从 [GitHub Releases](https://github.com/jevbot-dev/jevbot-mac/releases) 下载安装包，将 Jevbot 放入「应用程序」。
2. 在设置中配置 AI 引擎，连接需要操作的应用。
3. 按提示授予辅助功能、屏幕录制等权限。
4. 打开相关应用和项目，在 Jevbot 中新建任务，输入目标。
